# 02 - 数据库设计说明

数据库名称：`www_cnshopmate_c`（MySQL）。

## 1. `users`（用户表）
| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | bigint | PK | 主键 |
| `username` | varchar(64) | UNIQUE | 登录用户名（全局唯一） |
| `name` | varchar(100) | NOT NULL | 显示姓名/昵称 |
| `email` | varchar(150) | UNIQUE | 电子邮箱（全局唯一） |
| `status` | tinyint | DEFAULT 1 | `1` 启用 / `0` 禁用 |
| `is_admin` | tinyint(1) | DEFAULT 0 | 是否允许登录后台 |
| `password` | varchar(255) | NOT NULL | Bcrypt 哈希密码 |
| `last_login_at` | timestamp | NULL | 最后登录时间 |
| `last_login_ip` | varchar(45) | NULL | 最后登录 IP |

默认管理员（由 `DatabaseSeeder` 初始化）：
- 用户名：`admin`
- 密码：`admin123456`
- 邮箱：`admin@admin.com`

## 2. `dict_types`（数据字典类型 - 主表）
| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | bigint | PK | 主键 |
| `name` | varchar(100) | NOT NULL | 字典名称 |
| `code` | varchar(100) | UNIQUE | 字典编码 |
| `status` | tinyint | DEFAULT 1 | `1` 启用 / `0` 停用 |
| `remark` | varchar(255) | NULL | 备注 |

## 3. `dict_items`（数据字典项 - 从表）
| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | bigint | PK | 主键 |
| `dict_type_id` | bigint | FK (`dict_types.id`) CASCADE | 所属字典类型 |
| `label` | varchar(100) | NOT NULL | 显示标签 |
| `value` | varchar(100) | UNIQUE(`dict_type_id`, `value`) | 字典键值 |
| `color` | varchar(32) | DEFAULT 'teal' | 徽章色调 |
| `sort` | int | DEFAULT 0 | 排序（升序） |
| `status` | tinyint | DEFAULT 1 | 状态 |
| `remark` | varchar(255) | NULL | 备注 |

## 4. `system_settings`（系统设置表）
| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | bigint | PK | 主键 |
| `group` | varchar(50) | INDEX | 分组（如 `smtp`） |
| `key` | varchar(100) | UNIQUE | 配置键 |
| `value` | text | NULL | 配置值 |
| `label` | varchar(100) | NULL | 配置说明 |
