# 01 - 系统架构与技术栈

## 技术选型
- **后端框架**：Laravel 12（PHP 8.2+）
- **数据库**：MySQL（库名 `www_cnshopmate_c`）
- **前端组件库**：Layui 2.13.9（本地静态资源位于 `public/assets/layui/`，零外部 CDN 依赖）
- **后台主题**：自研护眼青灰（Sage Teal）单文件 CSS 覆写主题 `public/assets/admin/css/layui-sage-modern.css`
- **后台布局架构**：左侧可折叠导航 + 顶部多标签页（MDI Tabs）+ `iframe` 子页面隔离模式

## 目录约定
- `app/Http/Controllers/HomeController.php`：前台主页控制器
- `app/Http/Controllers/Admin/`：后台各业务模块控制器
- `app/Models/`：Eloquent 模型（`User`、`DictType`、`DictItem`、`SystemSetting`）
- `resources/views/home.blade.php`：前台主页
- `resources/views/admin/layouts/`：后台主框架母版与子页母版
- `public/assets/admin/`：护眼青灰主题 CSS 与 `AdminUI` 统一交互脚本
- `docs/`：按类型归类的开发文档与开发日志
