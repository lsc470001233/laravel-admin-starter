# 02 - 数据字典主从分屏

## 模块设计（`Admin\DictController`）
数据字典采用 EasyUI 经典的 **上下主从分屏** 交互模式：
- **上半区（主表 `dict_types`）**：分页展示字典类型，支持按名称/编码搜索、新增/编辑（居中弹窗）、删除（级联清理明细项）。
- **下半区（从表 `dict_items`）**：点击主表任意一行立即高亮并异步拉取 `/admin/dicts/types/{dictType}/items`，支持新增/编辑字典项（居中弹窗，含 6 种现代软色徽章色调与排序值）。
- **拖拽调高**：中间分隔条支持鼠标上下拖动，实时调整主表与从表的可视比例并自动触发 `table.resize()`。
