# 01 - 认证与用户管理

## 登录认证（`Admin\AuthController`）
- 登录页路由：`GET /admin/login`
- 提交路由：`POST /admin/login`
- **双凭证登录**：输入字段 `account` 自动识别是否为邮箱格式（`FILTER_VALIDATE_EMAIL`），分别匹配 `users.email` 或 `users.username`。
- **安全校验**：校验密码哈希、`status === 1`（启用状态）、`is_admin === true`（管理员权限），登录后更新 `last_login_at` 与 `last_login_ip`。

## 用户管理（`Admin\UserController`）
- 页面路由：`GET /admin/users`
- 数据接口：`GET /admin/users/list`（返回 Layui Table 标准 `{ code: 0, count, data }`）
- 新增/编辑：采用 **右侧抽屉**，`username` 与 `email` 均强制全局唯一校验。
- 重置密码：采用 **居中弹窗**，支持 `confirmed` 二次确认。
- 状态切换与删除：默认管理员 `admin` 与当前登录账号受保护，禁止误禁用或误删除。
